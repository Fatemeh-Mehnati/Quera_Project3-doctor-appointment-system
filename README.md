# Doctor Appointment System

A Django-based doctor appointment system developed as a team project.

## Features

- User registration and authentication
- OTP-based login
- Doctor search and filtering
- Doctor profiles
- Appointment booking and available time slots
- Wallet and payment management
- Reviews and ratings
- Automated and manual testing
- Docker and PostgreSQL support

## Technologies

- Python
- Django
- PostgreSQL
- SQLite
- Docker & Docker Compose
- HTML / CSS
- Git & GitHub

## Running the Project

```bash
git clone -b main https://github.com/Fatemeh-Mehnati/Quera_Project3-doctor-appointment-system.git
cd Quera_Project3-doctor-appointment-system
docker compose up --build
```
The application will be available at:
```
http://localhost:8000
```
